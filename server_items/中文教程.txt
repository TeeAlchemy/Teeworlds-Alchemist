物品添加格式
```

"id": 35,
"name": "Part: 模块名",
"desc": "Part desc",
"capacity": 0,
"placeable": [3],
"max": 0,
"max_place": 0,
"formula": {
    "Log": 0,
    "Coal": 0,
    "Copper": 0,
    "Iron": 0,
    "Golden": 0,
    "Diamond": 0,
    "Enegry": 0,
    "Zombie's Heart": 0
}

```
功能介绍
id：此物品在代码里分配的ID
name：物品的名字，请用英文，且小于64个字母
desc：物品介绍，请用英文，且小于64个字母
capactiy：物品的承载力/重力
placeable：该物品可以装进哪种物品，只有卡牌和模块拥有该属性
max：最多可以合成几个该物品
max_place：如果该物品可以插入别的物品，那么这个用来填最大可放置数量
formula：合成配方，后面跟的是 物品名+所需数量
    如：
    "Log": 100
    就是需要100个木头来合成
    并不仅限材料，你也可以：
    "Diamond Pickaxe": 1
    这代表合成需要消耗1把钻石镐

物品种类对照表
0 = 镐子
1 = 斧头
2 = 剑（作用在所有武器上）
3 = 炮塔
4 = 材料
5 = 卡牌
6 = 模块
